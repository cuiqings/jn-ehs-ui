# 投入台账页面

## 功能描述

投入台账页面用于展示企业安全生产投入费用的年度预算信息，包括：

- 年度筛选功能
- 预算卡片展示
- 下载、上传签字版、查看等操作

## 文件结构

```
inputRecord/
├── index.vue          # 主页面组件
├── api.ts            # API接口定义
├── mockData.ts       # 模拟数据
├── types.ts          # TypeScript类型定义
├── hooks/
│   └── useContent.ts # 业务逻辑hooks
└── README.md         # 说明文档
```

## 主要功能

### 1. 年度筛选
- 支持选择不同年度查看对应的预算信息
- 默认显示2024年数据
- 点击查询按钮刷新数据

### 2. 预算卡片展示
- 每个年度显示为一个独立的卡片
- 包含年度标签、标题、预算金额、状态等信息
- 响应式布局，支持移动端适配

### 3. 操作功能
- **下载**：下载对应年度的预算文档
- **上传签字版**：上传已签字的预算文档
- **查看**：查看预算详细信息

## 技术特点

- 使用 Vue 3 Composition API
- TypeScript 类型支持
- 响应式设计
- 模块化代码结构
- 统一的错误处理

## 使用方法

1. 在路由中配置页面路径
2. 根据实际需求修改API接口
3. 调整模拟数据结构
4. 自定义样式和交互逻辑

## 注意事项

- 当前使用模拟数据，实际使用时需要替换为真实API
- 文件上传功能需要根据具体需求实现
- 可以根据业务需求扩展更多功能
